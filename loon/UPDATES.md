# Update your plugins

1. Open Loon’s plugin list.
2. Choose **Update** on your existing Showrov plugin.
3. Open its settings, check the description and confirm your Access Key is saved.
4. Keep the plugin enabled and restart the target app.
5. After a Spotify update, sign out and sign in again while Loon and the plugin are enabled. Use Normal audio quality.

Use the permanent [plugin URLs](https://github.com/showrovbd/youtubepremiumios/blob/loon-preview/loon/apps/README.md) for ongoing updates. If an older entry uses a numbered filename or a fixed release link, replace its URL once with the current Plugin URL. Keep only one enabled copy per app.

For quiet YouTube use, select **When to Notify → Manual only**. To mute all access notices, turn **Access Notifications** off. Status changes reports each changed access result once.
