# Install all five plugins

Already installed? Change only any outdated plugin URLs using [these instructions](UPDATES.md), then use Update in Loon. All five active files share the same folder and keep their filenames for future updates.

To keep your routing and certificate, update the matching entries in the current configuration’s `[Plugin]` section from [this list](Showrov-Plugin-Entries.txt). Retain your app keys and settings and avoid duplicate enabled entries.

Optional first-time profile: [Open in Loon](https://www.nsloon.com/openloon/import?sub=https%3A%2F%2Fraw.githubusercontent.com%2Fshowrovbd%2Fyoutubepremiumios%2Floon-preview%2Floon%2FShowrov-All.conf) · [Download](Showrov-All.conf). Selecting this profile uses direct connections and system DNS; export the existing profile first. It is not an append-only import.

Use Loon 3.5.3 (1014)+, enter each matching key, and select/trust your own certificate. Enable HTTPS decryption, Rewrite and Script. Keys and certificates are not included. YouTube v10 is confirmed; Spotify v6 seeking and other app releases need device testing. [Support](https://t.me/montouch).
