# CapCut by Showrov

Network filtering and routing controls for CapCut.

[Add to Loon](https://www.nsloon.com/openloon/import?plugin=https%3A%2F%2Fraw.githubusercontent.com%2Fshowrovbd%2Fyoutubepremiumios%2Floon-preview%2Floon%2Fapps%2FShowrov-CapCut.lpxe) · [Plugin URL](https://raw.githubusercontent.com/showrovbd/youtubepremiumios/loon-preview/loon/apps/Showrov-CapCut.lpxe) · [Contact Showrov](https://t.me/montouch)

## What this version provides

- Filters two CapCut logging and monitoring hosts.
- Uses your selected Loon policy for matching CapCut connections.
- Supports a regional connection when you select an existing proxy server.
- Works through native network rules, with no MitM certificate setup.

**Version 1 does not unlock CapCut Pro, remove video watermarks or change export quality. Telemetry filtering is not a verified ad blocker.**

## Install

1. Use **Loon 3.5.3 (1014) or later**.
2. Disable **CapCut Request Diagnostics by Showrov** if it is installed.
3. Tap **Add to Loon**, or paste the Plugin URL into Loon's plugin list.
4. Open this plugin's configuration and explicitly select **DIRECT** as its policy if you have no proxy server.
5. Enable the plugin, connect Loon, then close and reopen CapCut.
6. Check that effects load and a short video exports. If either stops working, disable the plugin and [Contact Showrov](https://t.me/montouch).

## Select a region

Add a compatible proxy server to Loon, then select that server or its policy group in this plugin's policy setting. The server's location determines the network region. Choosing **DIRECT** uses your normal connection. This plugin does not include a server or change your Apple account country.

## Controls and updates

The plugin's enable switch turns its filtering and routing on or off together. Its policy selector controls the route. Version 1 has no separate custom switches for telemetry, watermarks, Pro access or export quality.

Use **Update** on the same plugin entry for future versions. Avoid enabling duplicate copies. iPhone compatibility is awaiting device confirmation.
